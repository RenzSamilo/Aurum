# Code of Conduct

Aurum follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep feedback about the work. Harassment of any kind isn't accepted.

To report a problem, contact the maintainer privately through GitHub ([@RenzSamilo](https://github.com/RenzSamilo)). Reports are handled confidentially.
