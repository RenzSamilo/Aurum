# Aurum

Design system: one token source, a React library (`packages/react`) and a Flutter library (`packages/flutter`). Read `.claude/skills/aurum/SKILL.md` before building or changing UI, and run `pnpm aurum rules`.

- Cheat sheet: `pnpm aurum list | show <component> | tokens | kits | rules`
- Catalog and how Aurum grows: `catalog/README.md`
- Checks: `pnpm catalog:check && pnpm guard && pnpm typecheck && pnpm test`, plus `flutter analyze && flutter test` in `packages/flutter`
